# Simple Blog App - IDEAS BAZE Capstone Project

## Overview
This Simple Blog App is a capstone project developed as part of the IDEAS BAZE program. It's a web application that allows users to create, read, update, and delete blog posts. The app demonstrates fundamental web development skills and serves as a showcase of the developer's learning journey in the program.

## Features
- User Authentication: Register and login functionality
- CRUD Operations: Create, Read, Update, and Delete blog posts
- Responsive Design: Works on various screen sizes
- Clean UI: Simple and intuitive user interface
- Search Functionality: Find posts by keywords

## Technologies Used
- Frontend: HTML, CSS, JavaScript (Bootstrap)
- Backend: (Node.js/Python/other - Django)
- Database: (MySQL/MongoDB/other - MySQL)
- Authentication: (JWT/OAuth/other - JWT)

## Installation
1. Clone this repository: `git clone [https://github.com/masha-a-m/simple-blog-app]`
2. Navigate to the project directory: `cd simple-blog-app`
3. Install dependencies:
   - Frontend: `npm install` (in client directory)
   - Backend: `npm install` (in server directory)
4. Set up environment variables (create a .env file based on .env.example)
5. Run the application:
   - Backend: `npm start` (or `node server.js`)
   - Frontend: `npm start`

## Configuration
Before running the app, you'll need to configure these environment variables:
- `DB_CONNECTION_STRING` - Your database connection URL
- `JWT_SECRET` - Secret key for JSON Web Tokens
- `PORT` - Port to run the server (default: 3000)

## Usage
1. Register a new account or login with existing credentials
2. Create new blog posts from the dashboard
3. View all posts on the home page
4. Edit or delete your own posts
